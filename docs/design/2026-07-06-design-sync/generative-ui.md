## 0. 阶段定位（按 journey §3 优先级阶梯）—— 先读这一节

journey 把旅程定义为**环**（不是漏斗）：発見 Discover → 判断 Decide → **計画 Plan（chat）** → **歩く Walk（审判时刻）** → 残す Keep → 分享物回流 Discover。

generative UI 主要服务 **計画 Plan** 段，产出物 = **路线**（journey 明示：Route 是**核心对象**，产品的家 = 「マイルート」，不是会话列表）。

**关键分期（这是之前跑偏的地方，务必守住）：**
- **Plan Phase 1（现在做）= 単列流 V3**：generative UI 以 **inline 卡**出现在**单列对话**中。
- **chat Phase 2（桌面双栏 / 侧栏工作台）= 已被 journey 降级到「环闭合后才做」**。之前探索的双栏 A/C/D、三栏、侧栏宽度 32/40/56% —— **全是 Phase 2，不是现在**。
- **审判时刻在 歩く Walk**：最高优先级、**零实现**，journey 让它**插队**于 Phase 2 之前（创始人本人现场弃用四件套 Maps+相册+Anitabi+小红书）。
- **inline 路线卡的「点开」归宿** = `/routes/:id` 路线详情 → **歩くモード**（Route 随旅程变形：预习版 → 现场入口 → 纪念版），**不是**桌面双栏编辑器。

**两条必守边界（Plan 段断点）：**
- **J6**：发送后**必须有流式反馈**，否则用户感知「产品坏了」。→ 分步思考动画 + 文字打字机 + 卡片骨架回填正是兑现它。
- **J7 / P5**：**登录墙立在「保存」**（chat 可匿名用；路线分享面必须公开免登录）。

## 1. generative UI 指什么

向导回复**不只是文字气泡，而是动态生成的可交互 UI 块**：问聖地 → inline **路线卡**；信息不全 → inline **聞き返しチップ**；丢截图 → inline **写真検索結果**。由 AI 的结构化输出决定「这条回复渲染哪个组件、填什么数据」。

---

## 2. 业界主流做法（curated kit）

共识：**不让 AI 直接吐 HTML**。主流 = 「**固定组件库 + AI 用结构化输出（tool/function calling 或 JSON schema）选组件并填数据**」，前端用注册表 `type → 组件` 渲染。代表：Vercel AI SDK `streamUI`、ChatGPT Canvas / apps、Claude Artifacts、Thesys C1、v0。

**inline vs 侧栏的分界 = 生成物是「一次性消费」还是「需反复编辑/参照」：**
- 一次性、轻量 → **inline 对话流内**（聞き返し、写真結果、单点预览、比較、确认）
- 持续演进的工件 → **侧栏 / canvas / 独立页**（ChatGPT Canvas、Claude Artifacts 的模式）

本产品的路线属后者，但按 journey **Phase 1 先做 inline 卡**，工件的"持续编辑面"由 `/routes/:id` 详情页 + 歩くモード承担（Phase 2 才上桌面双栏侧栏）。

## 3. 本产品的形态

### Phase 1（现在）— 单列流 + inline 卡
- 单列对话；发送 → **流式三段**（J6）：① 文字（打字机）② 卡片骨架 ③ 数据回填、就地激活。
- **inline 路线卡**：地图缩略 + spots + 总时长；CTA = **歩くモードで出発**（→ 审判时刻）/ **保存**（→ J7 登录墙）。
- 轻量块也 inline：**聞き返しチップ**（反问选项）、**写真検索結果**、**スポット单点预览**、**比較スライダー**。
- 卡上「开いて編集 / 詳細」→ `/routes/:id`（预习版 → 现场入口 → 纪念版），**不是**桌面双栏。
- 降级：未知 type / 数据缺失 → 回退文字摘要，绝不白屏。

### Phase 2（环闭合后）— 桌面增强
桌面双栏侧栏（默认 ~40%，编辑/歩くモード预览展开 ~56%）、历史路线、机位模式、SEO 规模化。**现在不做。**

## 5. 原型落法（mock + 动画）

- 假数据驱动；如需真生成可用 `window.claude.complete`（输入 → 结构化 JSON → 渲染组件，后续可选）。
- **动画**：流式三段（文字打字机 → 骨架淡入 → 数据回填错峰浮现）；卡内 spots 拖拽重排用 FLIP。
- 入场动画守「可见态为基态、从隐藏态进入」（探针 gate），保证静态截图 / 打印 / reduced-motion 也能看到内容。
