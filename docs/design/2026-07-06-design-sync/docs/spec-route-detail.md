# spec — 路线详情 /routes/:id（07-03 定稿 · 单页活文档）

对应画布：`路线详情 状态总览.html`（v1 探索存档：`… v1.html`）· 可点 demo：`路线详情 demo.html`（localStorage `route-demo-v1`）。

## 1. 概念（推翻三时态）
**单页活文档 · 无模式**。页面永远是同一张：appbar → hero → 地图卡 → 时刻表 → sticky dock。没有 segmented/时态切换件；**数据点亮元素**：
- 平日：什么都不多。
- 当天（きょうは巡礼日）：appbar 下金条「きょうは巡礼日！→ 歩くモードへ」+ 地図自动展開。
- 完走后：hero 完走徽章（完走 5/5 ✓）+ 行✓ + 対比図段自现。
- 优先级：**完走＞当天＞平日**（完走当天不再喊去 walk）。部分打卡的平日：✓保留（活文档不改写历史），无金条。

## 2. MODE（形态，与数据正交）
静息（hero 首屏、地图＝紧凑卡 132px）⇄ 地図展開（地图升格吃满、时刻表 sheet 化 352px、grab 下拖/たたむ收起）。FLIP 360ms cubic-bezier(0.4,0,0.2,1)，与工作台毕业同族。任何数据态都可手动展開/收起；展開**不带来**金条。当天默认展開，其余默认静息。<1024 桌面不适用。

## 3. 金 CTA（每屏唯一，sticky dock 渐变承接）
平日＝しおりを共有 · 当天＝歩くモードへ（＝金条，dock 退 cream：共有/Mapsで開く）· 完走＝記念しおりを作る。編集する＝cream→Chat A2b 引用编辑。

## 4. 时刻表（画面＞地点＞时刻）
行＝HH:MM｜轨道点｜帧缩略 **104×64**（話数 tag「第N話 MM:SS」，帧404→渐变+tag）｜站名+chips（つぎ=金框/受付許可制=warn/ハイライト=★dot）｜meta。walk 胶囊独立行（徒歩N分+沿途一句；バス/船=接驳 pill 仅展示，transit=roadmap）。打卡后行：时刻→实际打卡时刻+「ここに来た! ✓」。

## 5. 地图（図釘即画面）
pin＝**48px 帧图钉**：済✓teal 徽章 / 現在 58px 金环★ / 未访白底序号。路径＝暖棕虚线 2 9 round。金色路线 pill 常驻（带进度 N/5）。static-first；展開态才可操作，「現在地へ◎」。

## 6. 桌面 R-DESK 1440（拉满宽三栏）
430 hero+帧缩略时刻表 ｜ 中央大地图（主役，hover 図釘⇄行连动）｜ 270 rail：QR「旅へ持っていく」+ 名場面 ×3+N→機位ブラウザ + 出典 CC BY-NC-SA。顶栏：标题+状态 chip（出発前等）+編集(cream)+金 CTA。

## 7. 規模态（G4，结构性、不靠人气数据）
- **≥7 站**：時間帯手风琴（午前/午後/夕方），段头＝件数+徒歩+跨度，当前段展开、追随滚动。
- **多日**：day 段一级结构（1日目✓收起/きょう展开+金条/未来日收起 op.75）。
- **一点多图**：行只放代表帧+「Nカット▸」→機位ブラウザ sheet：話数 chip 筛选+写真あり filter+代表 tag（金）+出典行；dock＝代表を変える/この構図を目標に★（待裁决是否接 Walk）。
