施工规则

排序 · 圈泡 · 环 · 权利

名場面 TOP＝カット数順

结构性排序，不依赖人气数据（07-02 裁决：按没有设计）。tile 右上角＝カット数 pill；tap→機位ブラウザ sheet（路线详情 G4c 同件，公開页无个人対比図 badge）。「写真あり ⊙」＝haveImage filter（61/89）。

圏泡（DS S5 定稿）

r=12+26√(n/max)，teal 22% fill+2.5px 描边。泡 tap→zoom 进该エリア→帧图钉（≤50 pin 铁律，超出聚合）。static-first：「地図を操作↗」才挂 GL。桌面 hover 泡⇄TOP 行连动。

金 CTA · 环闭合

每屏唯一＝AIにルートを組んでもらう→ Chat 预填作品上下文（「君の名は。で行きたい」，C0 起步，出发地+时间必问照旧）。ルート例卡→路线详情（公开只读）。share 回流/SEO 都落这页＝発見边。全页未登录可浏览。

作品 color · hero

API 有作品主色：只 tint hero 渐变与 key art 占位，cream 骨架/按钮/文字不动。B 方向 hero＝TOP1 帧 blur-fill（Walk B′ 同族，帧不裁切）。帧 404→渐变+「第N話 MM:SS」。

规模边界

響け156件/ぼっち45件同构：TOP 固定前 4+「ぜんぶ見る」；エリア泡最多 6 个（再多聚合为「ほか N エリア」泡）；ルート例 0 条→段落消失，只留金 CTA（不摆空架子）。
