## 0. 谁在用、什么时候用（三个时段 × 三类人）

| 人 | 从哪来 | 用的时段 | 设备 |
|---|---|---|---|
| **P0 创始人**（dogfood 基准） | 自己排路线 | 全程 | 桌面排 → 手机走 |
| **P1 小红书圈**（中文） | 刷到 9:16 竖图しおり → 评论区链接 | 発見→改装 | 手机 |
| **P2 X 圈**（日文） | 链接卡（OG 图）点进来 | 発見→改装 | 手机/桌面 |

三个时段的心理状态完全不同，同一条路线要以不同形态出现：
- **旅行前**（在家，可能桌面）：好奇→评估→规划。有耐心，信息密度可以高。
- **现场**（手机、单手、强光、弱网）：焦虑+兴奋。「我在哪/下一站/机位对不对」。每多一次切 app 就输一点。
- **走完后**（情绪最高点，每小时衰减）：想炫耀。分享物必须「零编辑、马上能发」。

## 1. 环的文字走查 — 三条主线

### 主线 A：首次用户 · 搜索型（「看完番想去」）

**①発見** 看完『君の名は。』→ 进产品（Landing「Start Exploring」/ 首页搜索框 / 直接 chat）。
**②提问** 首页搜「君の名は。の聖地に行きたい」→ 跳 chat（URL `?q=`，A2：用户气泡乐观渲染，不用重打）。
**③等待（B2 阶梯）** agent 跑 `resolve_anime`：<1s 只有狐狸 typing（B2a）→1–4s 出管线+Bangumi 徽章+狐狸计数（B2b）→≥4s 追加作品情绪卡（B2c）。**纯文字回合永不出管线。**
**④圈澄清（C2g）** 『君の名は。』全国 89 件、6 圈 → 必须先选圈（飛騨23/東京31/諏訪12…/すべての圏を見る→C3b 圈总览）。**用户消息已含地点则整步跳过**（「飛騨に行く」→直接⑤）。单圈作品（如『響け』只在宇治）也跳过。
**⑤看点位（C3a）** `search_bangumi` → **点位卡组 top-6**（动画截图封面 16:9 + カット tag + 勾选框，默认按人气/有图预选）+ 静态地图（23 件 pin）+ AI 总结（「駅から神社までゆるい登り…」）。
　此处用户有 **三个出口**：
　- **a. 满意 top-N** → 直接说「この5件で組んで」/ 点重排条 → 走⑥。
　- **b. 想看全部 23 件** → 点卡组 footer 的 **「すべて見る → 23件から選ぶ」→ 选点工作台 SP**（见 §2，这就是 chat→SP 的唯一正门）。
　- **c. 微调勾选** → 勾/取消 → 底部浮出金色重排条（E2a）→「ルートを組み直す」。
**⑥路线前提** 排时刻表需要 **出发地+出发时间**（TimedItinerary 的 HH:MM 从这来）。
　⚠ **spec 空白点**：44 态里没有这一步。两个候选方案（待裁决，见 §4-Q1）：
　- 方案甲（我在画布里画的 C2t）：条件缺失时 clarify 一次「どこから・何時ごろ？」（chips：駅から9:30 / いまいる場所→C4 / 場所を入力 / おまかせ）；说全则跳过。
　- 方案乙：不问，默认「圈玄关站+合理时段」直接生成，靠生成后的追问 chips（夕方スタートに等）改。
**⑦路线诞生（C5）** `plan_route` → B2d 先插时刻表 skeleton → **TimedItinerary**（英文眉标/日文卡名/pacing pill/HH:MM 站粒度/walk 胶囊/金★高光/帧缩略）+ 地图升格（轨迹+按步行序重编号+金色路线 pill 常驻）+ AI 总结 + 追问 chips。**时刻是真的，能据此买车票。**
**⑧细化循环**（可迭代 N 轮）追问 chips（もっとゆったり/夕方は?/カフェ足して）→ 走 agent 回合 → **E1 活文档**：旧卡降「以前の版」（op .55），新卡带「更新版」+diff chips 落底。勾选变化 → **E2 旁路**（不经 agent：「✓ 再計算 1.2s」，无管线戏）。
**⑨保存（P5 登录墙唯一位置）**「保存する」→ magic link / ゲスト逃生口。卖点=**跨设备带路线**：桌面排好 → QR/同账号 → 手机（D5d）。看/改/排全程免登录。
**⑩出发当天** 手机开 `/routes/:id`（現場入口时态）→ 「歩くモードで出発」→ scene-cut 转场 → `/walk`。
**⑪现场（J9–J14 审判时刻）** 见 §3。
**⑫完走→残す** 最后一站打卡 → 完成屏（狐狸举旗「巡礼完了!5/5」）→ 「しおりを作る」（金，趁情绪）→ 9:16 竖图 + 免登录 /share 链接 → 发小红书（存图）/X（链接卡）。**分享物=下一个人的入口，环闭合。**

### 主线 B：回流用户 · アレンジ型（⚠ 比主线 A 更高频，journey 走查定论）

①小红书/X 刷到 → ②`/share/:routeId` 免登录落地（「✓ 作者已走完」徽章+每站✓+动画帧×作者实拍 pair grid——信任的来源）→ ③金色 CTA「自分用にアレンジ」→ ④chat **A2b 引用态**（composer 上方「📎 参照中：〈路线名〉」pill）→ ⑤一句话改装（「出発は大阪、午前だけ」）→ agent 以引用路线为底重组 → C5′ → ⑥保存→走→完走→**又一个分享物**。
设计含义：**A2b 的体验优先级高于 A1 空态**——「拿别人的路线来改」是环的主干道，空输入框才是支线。

### 主线 C：浏览型 · 判断段（「这作品值得专程吗」）

①`/anime/:id` 作品公开页（免登录）：名場面 TOP（按カット数）+ 圈泡分布图 + 示例路线（别人走过的缩略）→ ②评估「值不值得专程」→ ③「AI にルートを組んでもらう」→ chat 種子流 → 汇入主线 A 的③。

## 2. chat → 选点工作台（SP）的精确路径 ★你问的这个

**入口（就两个，都在卡上，不在菜单里）：**
1. **C3a 点位卡组 footer**：「すべて見る → 23件から選ぶ」。触发条件=单圈搜索结果落地后，用户觉得 top-6 不够。
2. **C3b 圈总览** 的圈卡「この圏で絞り込む」→ 先下钻到该圈的 C3a → 再从那里「すべて見る」。（圈总览自己不直接进 SP——先看 top-6 是刻意的漏斗。）

**形态**（按端分）：
- Phase 1 / V3（现在做的）：**全屏 takeover**，从流上滑入，头部「← チャットに戻る」。
- Phase 2 / V1 桌面双栏：右栏原位变形（不离开对话）。
- 移动端：列表全屏 + 右下「地図」浮钮切换视图，托盘 sticky 底部。

**里面发生什么**：浏览（分组 話数⇄エリア + 排序 おすすめ/カット順/駅近 + 写真あり filter）→ 勾选（行勾选 ↔ 右侧地图 pin 实时同步：选中=teal 实心带序号）→ 底部托盘（已选缩略 chips + 拖拽柄）→ 顺序模式（おまかせ/物語順/手動——**浏览排序 sort ≠ 路线顺序 order**，这是两个独立概念）→ 金色 CTA「このN件でルートを組む」。

**出口（关键：SP 不产路线，它只改「选中集合」）**：CTA → **SP6 = 走 E2 旁路**（selected_point_ids + 顺序模式，不经 agent、无管线戏，只显「再計算 1.2s」）→ **返回 chat 流**，路线卡按 E1 规则出新版本。若此时还没有路线（第一次选完就组），则同样旁路直接生成 C5 卡（前提缺失时按 §1-⑥ 裁决的方案处理）。

**规模分档**：≤300 件直接渲染列表；>100 件自动反转为 **SP8 草稿编辑模式**（agent 先选 8 件，用户「入れ替え」局部替换，永不平铺）；**SP9 锚点委托**（标 1–3 个「絶対行く」→ 其余おまかせ）。SP8/9 规则已锁、本期不出图。

## 3. 歩く段文字走查（Step 1 施工前的需求确认）

**进入**：`/routes/:id` 現場入口态（当天打开自动置顶「歩くモードで出発」）或路线卡预留位。scene-cut 狐狸转场（「明显去某处」）。
**屏幕结构**（Citymapper 范式，当前站置顶放大）：
1. 顶部：返回 + 金色路线 pill（路线名常驻）+ 进度格 `●●●○○`（J13 的「走到第几站」）。
2. **walk-hero 当前站卡**（屏幕主角）：「NOW → 3/5」+ 超大站名（30px+/900，户外强光可读）+ カット tag/滞在/注意事项 + **场景对照帧**（16:9 内嵌，替代翻相册）+ 「📷 構図をくらべる」→ 机位对照子视图（半透明 ghost 叠加 + 待复刻构图清单，拍到一张勾一张，勾选数喂しおり完成率）。
3. **「🧭 Mapsで開く」深链**（不自建导航，J12）+ 到站 ETA 行（「味処古川から徒歩9分 · 11:13着」）。
4. 下一站行（低调）：「つぎ → 飛騨市図書館 · 🚶7分」。
5. 屏幕下半单手区：「📍 近くにあと N スポット」（sheet 滑出，J11）+ **「✓ ここに来た!」金色全宽**（vibrate → 进度+1 → 下一站自动置顶，J13）。
**环境态（J14）**：白天标准 / 户外强光（字号再放大一档、白底、粗边）/ 夜间 / 离线弱网（route bundle：JSON+帧图+每站静态 PNG；打卡本地排队回网 flush）/ 完走→しおり握手。
**四件套映射自检**：Maps=深链✓ 相册=scene-thumb✓ Anitabi=近くsheet✓ 小红书攻略=路线自带✓痕迹✓ 心算=进度格✓。
