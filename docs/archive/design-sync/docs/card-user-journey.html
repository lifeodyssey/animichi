  • J11 "附近还有什么":替代现场开 Anitabi(search_nearby 后端已有,缺现场 UI)
  • J12 导航深链:每站"在 Maps 打开"(P3:导航让赢家赢,不重造)

  • J14 现场环境约束:户外强光对比度(DESIGN.md A11y outdoor 条款)、弱网(static-first 已定)、单手操作

4前提与证据记录

前提 Premises(创始人确认)

P1环形旅程,不是漏斗
P2Walk 是审判点(现场决定产品生死)
P3四件套只赢三件:导航让赢家赢(不重造 Maps),机位经验 UGC 短期明示放弃

P4修订版:Keep 产出物 = 免登录公开分享页 + 自动 OG 竖图,同一资产喂两渠道(图→小红书、卡片→X);时序上 Walk 先于 Keep;大规模 SEO 后置。

  • 多图分层露出:站(50m)→ 机位(10m)→ カット;详情页 filmstrip 折叠(代表帧×3 + "+N")→ 全屏机位浏览器 → 歩くモード当前站展开为待复刻构图清单(拍到一张勾一张,喂しおり完成率)。
  • 离线与认证策略:route bundle 预载(JSON + 帧图 + 静态地图);看缓存路线不需要在线鉴权,写 / 同步才要;现场 token 过期不锁内容,打卡本地排队回网同步。
