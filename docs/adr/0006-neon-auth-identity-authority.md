# Neon Auth is the sole human identity authority

Animichi will accept Neon Auth as its only human JWT issuer. Web owns the Better Auth login integration. Edge is the sole browser-token verifier: it strips Authorization and every caller-supplied identity header, verifies the Neon token once, and forwards an unforgeable internal human identity over service bindings; downstream Workers remove browser-JWT verification and reject direct or forged identity input. Anonymous access remains a separate signed identity policy.

The hard cut cannot use the current redacted staging issuer placeholder. Before fallback deletion, infrastructure as code must derive and pin issuer/JWKS from the exact staging Neon branch, provision the non-production QA login path through declared secret/configuration stores, and prove a real login token at Edge plus the internal Users boundary. Only then are Supabase Auth, dual-issuer fallback, the activation flag, and Animichi-issued `sk_*` machine credentials removed rather than supported as compatibility paths. This trades migration convenience for one fail-closed security boundary; staging may be reset, while production user and data migration remains a separate pre-production gate and every campaign revision stays production-ineligible.
