# One published turn interface

`POST /v1/chat` is the only published Agent turn interface. Its text and selection commands, progress events, terminal projections, and pre-stream errors are defined by the Contract published language and mapped to context-local models at the boundary. A successful call uses the AI SDK SSE protocol; validation and admission failures occur before stream start, while later failures become terminal events. TurnAdmission reserves once before streaming, TurnOutcome owns phase-aware cancellation and exactly-once settlement, and AgentTurn owns command execution and persistence. In the local/staging campaign, Agent startup and every TurnAdmission run a bounded indexed expired-lease sweep before quota and budget reads; no background scheduler, queue, or Workflow is added. Non-turn Agent capabilities remain separate interfaces. The legacy `/v1/runtime` turn surfaces and package-local wire mirrors are deleted, accepting a hard staging cutover in exchange for one public test seam and one lifecycle implementation. Production no-traffic liveness is a later pre-production decision.
