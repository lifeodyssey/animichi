④ orchestrator ci.yml — 三场景

① pull_request  affected 只跑改的,不部署
changes→ci-agentci-catalogci-frontendintegrationsecurityeval(affected)→✗ 无 deploy
② push main  全跑 → 自动 staging + 部署后 api/e2e
changes→ci-* · integration · security · eval(全跑)→needs 全绿?→deploy-staging→api+e2e
on staging
└ 任一闸红 → deploy 被 needs 挡
③ push tag v*  全跑 → 人工 → prod + smoke
changes→ci-*(全跑)→needs 全绿?→⏸ human approve
environment=production→deploy-prod→smoke
on prod

⑤ 分层 gate(按速度 — 严且快反馈)

pre-commit <5sruff · oxlint · gitleaks  (本地 hook,挡在 push 前)
CI PR(并行)ci-* + integration + security + eval  — 各自 fail-fast,互不阻塞;秒级(ruff/tsc)先挂、分钟级(testcontainer/type-aware ESLint)并行
staging 部署后api + e2e(on staging)  — 验"部署出来真能跑";红则挡 tag→prod
prod 部署后smoke(on prod)  — core paths;红则告警/回滚
