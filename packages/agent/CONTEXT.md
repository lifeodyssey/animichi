# Agent domain

Ordinary rules used while finding pilgrimage places and answering a visitor. This context has
no HTTP host, storage engine or agent execution protocol.

| Term | Meaning |
|---|---|
| Selection outcome | Deterministic text describing the result of a structured user choice |
| Status value | Bounded external text that cannot alter server-authored status structure |
| Source tier | A web source's domain-based trust category |
| Host address class | The literal address/name category used by egress policy |
| Localized city name | A catalog city's display name in the reader's locale |

Contract owns Point and the public wire language. Edge hosts agent execution and consumes
these rules.
